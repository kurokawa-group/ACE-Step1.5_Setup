【完全版】ACE-Step (v1.5) ゼロから導入・最適化ガイド（HP Z840 / Quadro P6000 / Fドライブ）

構築先: F:\AI_Music\ACE-Step-1.5 対象: HP Z840 / Windows 10 GPU: Quadro P6000 (24GB / Pascal) ライセンス: Apache 2.0（商用利用可）

⚠️ Quadro P6000（Pascal世代・24GB）で確実に動かすための重要設定

  1. Float32 固定と vLLM 回避（NaN エラー防止）： Pascal世代（Compute Capability 6.1）は最新GPU用の高速エンジン（vLLM）に非対応であり、半精度（float16）では計算オーバーフローによる NaN or Inf latents エラーが発生します。起動時に set ACESTEP_DTYPE=float32 と --backend pt を指定し、さらに後述のパッチを適用することで、ネイティブPyTorchモードでエラーなく安定動作させます。
  2. 24GB VRAM のメリット： 大容量VRAMがあるため、メモリ節約用の「CPUオフロード」に頼ることなく、生成本体と音声分析用モデル（5Hz LM）をVRAM上に常駐させて快適・高速に生成できます。
STEP 0

前提ツールの導入 ＆ Fドライブへのキャッシュ完全固定

Windows 10のコマンドプロンプトを開き、Git・Minicondaの導入と、Python環境・AIモデル保存先（約10GB以上）をすべて F:\AI_Music 配下に固定する設定を行います（すでにYuE2構築時にフォルダを作成済みの場合はそのまま上書き実行して問題ありません）。

  • インストール先： F:\AI_Music\ACE-Step-1.5
  • モデル保存先： F:\AI_Music\hf_cache
Command Prompt（コマンドプロンプト） 
winget install -e --id Git.Git
winget install -e --id Anaconda.Miniconda3
mkdir F:\AI_Music\hf_cache
mkdir F:\AI_Music\conda_envs
mkdir F:\AI_Music\pip_cache
setx HF_HOME "F:\AI_Music\hf_cache"
setx PIP_CACHE_DIR "F:\AI_Music\pip_cache"
重要： setx コマンドを実行したら、一度コマンドプロンプトを閉じてください（次に開くターミナルからFドライブ設定が有効になり、Cドライブの容量を消費しなくなります）。

STEP 2

Quadro P6000（CUDA 12.1）最適化版 PyTorch と本体の導入

STEP 1 で有効化した F:\AI_Music\conda_envs\acestep 環境のまま、Pascal世代の Quadro P6000 と最も相性が良く安定している CUDA 12.1 ビルドの PyTorch を先にインストールしてから、ACE-Step 1.5 本体をセットアップします。

Anaconda Prompt（acestep 環境内）

pip install -e .

※セットアップ完了後、Quadro P6000 が CUDA 12.1 ビルドで正しく認識されているか確認してください。

STEP 3

初回起動 ＆ ダブルクリック起動用バッチファイル作成（ポート 7866）

1. Quadro P6000 最適パラメータ（Float32・自動初期化）での初回起動

以下のコマンドを実行すると、初回のみ音楽生成モデルおよび音声分析用モデル（約10GB以上）が自動的に F:\AI_Music\hf_cache へダウンロードされ、ローカルWebサーバーが立ち上がります。

Anaconda Prompt（acestep 環境内） 
set ACESTEP_DTYPE=float32
acestep --port 7866 --backend pt --language ja --init_service true --init_llm true
  • float32 固定： Quadro P6000 での計算オーバーフロー（NaN エラー）を完全に防ぎます。
  • 自動初期化（--init_service true --init_llm true）： 音楽生成本体と音声分析用モデル（5Hz LM）を起動時に自動で読み込み、model not initialized エラーを防ぎます（初回のみモデルのダウンロードに数分かかります）。
  • ブラウザ起動： 黒い画面に Running on local URL: http://127.0.0.1:7866 と表示されたら、ブラウザで http://127.0.0.1:7866 を開きます。

2. 2回目以降の簡単起動用バッチファイル（start_acestep.bat）

メモ帳を開き、以下のコードを貼り付けて F:\AI_Music\start_acestep.bat という名前で保存してください（保存時にファイルの種類を「すべてのファイル」、文字コードを必ず「ANSI」にします）。次回からはダブルクリックだけで起動します。

F:\AI_Music\start_acestep.bat（文字コード：ANSI） 
@echo off
cd /d F:\AI_Music\ACE-Step-1.5
call %USERPROFILE%\miniconda3\Scripts\activate.bat F:\AI_Music\conda_envs\acestep
set ACESTEP_DTYPE=float32
echo Starting ACE-Step 1.5 (Quadro P6000 24GB Float32 Mode)...
acestep --port 7866 --backend pt --language ja --init_service true --init_llm true
pause
STEP 3.5

Quadro P6000（Pascal世代）向け NaNエラー対策パッチ

ACE-Step 1.5 の標準仕様では、Pre-Ampere世代（Quadro P6000 等）を検出すると内部で自動的に float16 が割り当てられ、生成時に NaN or Inf latents エラーが発生する場合があります。以下の手順で強制的に float32 を使用するように書き換えます。

  1. メモ帳や VS Code などのテキストエディタで、以下のファイルを開きます。
    F:\AI_Music\ACE-Step-1.5\acestep\core\generation\handler\init_service_orchestrator.py
  2. ファイル内を検索し、Pre-Ampere CUDA detected の直前にある self.dtype = torch.float16 を以下のように書き換えて上書き保存します。
init_service_orchestrator.py（書き換え後のコード） 
self.dtype = torch.float32
補足： ファイルを書き換えた後は、起動中のコマンドプロンプト（ACE-Step）を一度閉じ、start_acestep.bat から再起動するとパッチが有効になります。
STEP 4

ボーカルなし設定 ＆ 自作メロディ（WAV）の豪華伴奏化テクニック

WebUI（http://127.0.0.1:7866）上で、自作メロディを活かしながら商用利用可能なインスト音源を作るための設定基準です。

設定項目（WebUI上） おすすめの入力・設定値 効果・ポイント
Tags / Prompt（ジャンル指定） instrumental, no vocals, cinematic orchestral, emotional piano, lush strings, high quality 先頭に instrumental, no vocals を入れることでボーカル混入を確実に防ぎます。
Lyrics（歌詞欄） [instrumental] または空欄 歌詞テキストを入れるとAIが歌おうとするため、必ず空欄か構成タグのみにします。
Audio-to-Audio / Reference Audio DAWから書き出した自作メロディの guide.wav をアップロード 単音メロディ、またはYuE2で作ったコードを足したピアノ仮音源を読み込ませます。
Denoising Strength（変化の強度） 0.45 ～ 0.65（目安） 0.3～0.4： 原曲のメロディとリズムに極めて忠実に楽器を追加。
0.6～0.75： メロディの骨格を残しつつ、ドラムやベースを大胆にプロ編曲化。
